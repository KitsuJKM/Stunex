# Objetivos

## Propósito del documento

El presente documento define los objetivos que orientan el desarrollo del proyecto **Stunex**, estableciendo el propósito principal del sistema y los resultados específicos que se esperan alcanzar durante la implementación del Producto Mínimo Viable (MVP).

---

# Objetivo General

Desarrollar una aplicación móvil denominada **Stunex** que permita centralizar la organización académica de estudiantes de educación superior mediante herramientas de planificación, gestión de tareas, administración de recursos y seguimiento de actividades, mejorando su productividad y facilitando la administración de la información académica desde una única plataforma.

---

# Objetivos Específicos

## OE-01

Diseñar una interfaz móvil moderna, intuitiva y fácil de utilizar que permita a los estudiantes acceder rápidamente a las funcionalidades principales de la aplicación.

---

## OE-02

Implementar un sistema de autenticación seguro que permita el registro, inicio de sesión y recuperación de acceso mediante credenciales protegidas.

---

## OE-03

Desarrollar un módulo para la gestión de materias que permita registrar, modificar, consultar y eliminar la información académica correspondiente a cada asignatura.

---

## OE-04

Implementar un sistema de administración de tareas que facilite la planificación de actividades, el seguimiento de fechas límite y el control del estado de cada tarea.

---

## OE-05

Desarrollar un calendario académico que permita visualizar eventos, evaluaciones, entregas y demás actividades importantes del semestre.

---

## OE-06

Implementar un módulo para la gestión de horarios de clase que permita organizar las sesiones académicas de manera clara y accesible.

---

## OE-07

Desarrollar un sistema de almacenamiento de documentos académicos utilizando un servicio de Bucket Storage para facilitar el acceso a archivos desde la aplicación.

---

## OE-08

Implementar una biblioteca de recursos donde los estudiantes puedan organizar enlaces, documentos y materiales de estudio asociados a cada materia.

---

## OE-09

Incorporar herramientas complementarias que apoyen la productividad del estudiante, como una calculadora de notas y un temporizador basado en la técnica Pomodoro.

---

## OE-10

Diseñar e implementar una API REST segura que permita la comunicación entre la aplicación móvil y la base de datos mediante una arquitectura escalable.

---

## OE-11

Diseñar una base de datos relacional que garantice la integridad, consistencia y disponibilidad de la información almacenada por el sistema.

---

## OE-12

Aplicar buenas prácticas de ingeniería de software mediante el uso de control de versiones, documentación técnica, arquitectura modular y desarrollo incremental.

---

# Indicadores de Cumplimiento

Los objetivos del proyecto se considerarán cumplidos cuando:

- La aplicación permita el registro e inicio de sesión de usuarios.
- El usuario pueda administrar materias, tareas y horarios.
- Sea posible almacenar y consultar documentos académicos.
- El calendario muestre correctamente las actividades registradas.
- La aplicación consuma correctamente los servicios de la API REST.
- La información se almacene de forma segura en la base de datos.
- El sistema funcione de manera estable durante las pruebas del MVP.

---

# Relación con el Proyecto

Los objetivos definidos en este documento servirán como guía para el desarrollo de los requisitos funcionales, el diseño de la arquitectura, la implementación de la aplicación móvil y la evaluación del cumplimiento del alcance establecido para la primera versión de Stunex.
