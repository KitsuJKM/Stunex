# Justificación

## Propósito del documento

El presente documento expone las razones que fundamentan el desarrollo del proyecto **Stunex**, destacando su importancia, utilidad y beneficios para los estudiantes de educación superior.

Asimismo, se explica por qué la implementación de una aplicación móvil de organización académica representa una solución viable frente a las dificultades identificadas durante el análisis del problema.

---

# Justificación del Proyecto

La organización académica constituye uno de los principales desafíos para los estudiantes de educación superior. Durante un semestre, es habitual gestionar múltiples materias, tareas, evaluaciones, horarios, recursos digitales y actividades grupales, lo que requiere un seguimiento constante y una adecuada planificación.

Aunque existen diversas aplicaciones que ayudan a organizar parte de esta información, la mayoría se especializa en una única función, obligando al estudiante a utilizar varias herramientas de manera simultánea. Esta situación provoca que la información se encuentre distribuida en diferentes plataformas, aumentando el tiempo necesario para consultarla y dificultando su administración.

En este contexto surge **Stunex**, una aplicación móvil concebida para integrar en un único sistema las principales herramientas utilizadas por los estudiantes durante su proceso académico.

La centralización de la información permitirá reducir la fragmentación de los recursos, facilitar el acceso a las actividades pendientes y mejorar la planificación del tiempo mediante una interfaz intuitiva y enfocada en las necesidades reales del usuario.

---

# Justificación Tecnológica

El desarrollo de Stunex permitirá aplicar tecnologías modernas ampliamente utilizadas en la industria del desarrollo de software.

Entre ellas se encuentran:

- Flutter para el desarrollo de aplicaciones móviles multiplataforma.
- FastAPI para la construcción de una API REST moderna y de alto rendimiento.
- MySQL como sistema gestor de bases de datos relacional.
- SQLAlchemy como ORM para el acceso a la base de datos.
- JWT para la autenticación segura de usuarios.
- Bucket Storage para el almacenamiento de documentos y archivos académicos.

La combinación de estas tecnologías garantiza una arquitectura escalable, mantenible y preparada para futuras ampliaciones del sistema.

---

# Justificación Académica

El proyecto permitirá poner en práctica los conocimientos adquiridos durante la formación en análisis y desarrollo de software.

Durante su construcción se abordarán temas relacionados con:

- Ingeniería de software.
- Análisis de requisitos.
- Diseño de bases de datos.
- Desarrollo de APIs REST.
- Desarrollo de aplicaciones móviles.
- Gestión de autenticación.
- Integración de servicios de almacenamiento.
- Control de versiones con Git y GitHub.
- Documentación técnica.

De esta manera, el proyecto funcionará como una experiencia integral que reúne diferentes áreas del proceso de desarrollo de software.

---

# Justificación Social

La organización eficiente de las actividades académicas puede contribuir a mejorar la productividad y reducir el estrés asociado a la gestión de múltiples responsabilidades.

Al ofrecer una plataforma centralizada, Stunex facilitará el acceso a la información académica y promoverá hábitos de planificación más efectivos, favoreciendo el cumplimiento de tareas, evaluaciones y compromisos estudiantiles.

Además, la aplicación podrá servir como base para futuras funcionalidades orientadas al trabajo colaborativo y al acompañamiento del proceso de aprendizaje.

---

# Viabilidad del Proyecto

El desarrollo de Stunex es técnicamente viable debido a que el equipo cuenta con conocimientos previos sobre las tecnologías principales que serán utilizadas y dispone del tiempo necesario para construir un Producto Mínimo Viable (MVP).

La arquitectura seleccionada permitirá desarrollar el proyecto de forma modular, implementando cada funcionalidad de manera independiente y facilitando las pruebas durante el proceso de desarrollo.

---

# Beneficios Esperados

La implementación de Stunex permitirá:

- Centralizar la información académica en una única aplicación.
- Mejorar la organización de materias y actividades.
- Reducir el riesgo de olvidar tareas y fechas importantes.
- Facilitar el acceso a documentos y recursos de estudio.
- Optimizar la planificación del tiempo mediante herramientas integradas.
- Proporcionar una experiencia de usuario moderna, intuitiva y organizada.
- Establecer una base tecnológica preparada para futuras versiones del sistema.

---

# Conclusión

El desarrollo de Stunex responde a una necesidad real identificada en el entorno académico: la dispersión de la información y la falta de una herramienta que integre los principales recursos utilizados por los estudiantes.

Gracias a una arquitectura moderna, una aplicación móvil intuitiva y un enfoque centrado en el usuario, Stunex representa una solución viable tanto desde el punto de vista técnico como académico, constituyendo además una oportunidad para aplicar buenas prácticas de desarrollo de software y crear un proyecto con potencial de crecimiento.
