# 📚 Stunex

> Organiza. Aprende. Evoluciona.

## Descripción

Stunex es una aplicación móvil desarrollada para ayudar a estudiantes de educación superior a organizar su vida académica desde un único lugar.

## Tecnologías

- Flutter
- Dart
- Python
- FastAPI
- MySQL
- SQLAlchemy
- JWT
- Bucket Storage
